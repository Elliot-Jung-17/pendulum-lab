# Pendulum Lab 배우기 교육과정 지도

> 계획 버전: v2.1 안전 보강판
>
> 구성: 8개 과정, 86개 독립 단원
> 원칙: 일반 물리 입문 단원은 만들지 않고, 필요한 기초는 각 단원의 선수 개념 상자에서 설명한다.

## 1. 콘텐츠 공통 규격

각 단원은 다른 단원을 끝내지 않아도 열 수 있다. 선수 단원은 추천 경로일 뿐 접근 제한이 아니다. 모든 단원은 다음을 포함한다.

- 왜 이 문제가 필요한지 보여 주는 연구 질문
- 모델의 가정, 좌표, 기호, 단위
- 핵심 식의 단계적 유도와 항별 물리적 의미
- 근사와 유효 범위, 흔한 오해, 수치 계산의 실패 조건
- 노출 변수가 제한된 단원 전용 Focus Experiment
- 예측→실행→관찰→설명의 최소 1개 탐구 활동
- 전체 실험실에서 계속 탐구할 수 있는 canonical state 전달
- 참고 문헌·검증 가능한 예제·접근성용 수식 설명

- 같은 분석을 여러 과정에서 사용할 수 있지만, 같은 설명을 복사하지 않는다. 공통 개념 block을 참조하고 단원은 서로 다른 연구 질문을 가진다.
- 단원 제목과 실험 대상은 registry의 실제 기능 ID로 연결한다. 아직 구현되지 않은 기능은 콘텐츠만 먼저 공개하지 않는다.
- 과정 8의 연구 기능도 모든 사용자에게 열려 있으며 `Research mode`를 만들지 않는다.
- 한국어가 기준 콘텐츠이며 영어 번역 key와 용어집을 함께 유지한다.

## 4. 과정 제작 완료 조건

한 과정은 다음이 모두 충족되어야 완료다.

- 모든 단원이 schema validation과 링크 검사를 통과한다.
- 모든 식에 변수 정의·단위·접근성 설명이 있다.
- 모든 Focus Experiment가 실제 공용 엔진을 실행하고 deterministic fixture를 통과한다.
- 관찰 과제의 예상 결과가 허용 오차와 함께 테스트된다.
- 배우기→실험실 전달 뒤 시스템·값·단위·분석 설정이 보존된다.
- 모바일·키보드·screen reader 흐름과 한국어 줄바꿈을 확인한다.
- 내용의 과학적 정확성 검토 기록과 참고 문헌이 존재한다.
- `automated-verified`, `source-checked`, `human-reviewed`를 구분하며 AI 검토만으로 사람 검토 완료를 표시하지 않는다.
- S29 전환 전에는 모든 공개 단원이 최소 `source-checked`이고, 미완료 사람 검토 상태는 제품에 투명하게 표시한다.
